# oldge-ui

A Compose Multiplatform implementation of the **oldge-ui** design system: mobile components in the
aesthetic of mid-2000s software — thick glossy frames, dark bodies with a soft glow, chrome orb
buttons, LCD readouts, XP tray balloons — around a toxic lime accent, in three skins (Toxic, Media,
Crystal).

Nothing is built yet. Where the work stands and why it is ordered the way it is:
[docs/](docs/README.md) — start with the [architecture research](docs/research/research-architecture.md)
and the [backlog](backlog.md). The design system itself is vendored in
[reference/design-system/](reference/design-system/).

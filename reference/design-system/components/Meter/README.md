# Meter

Сегментный индикатор уровня на ЖК-стекле: заполненность, сигнал, нагрузка.

**Потребитель даёт:** `value` (0..1), `label` (пиксельная метка), `valueText`, `segments` (по умолчанию 20).

- Цвета делений фиксированы порогами: до 60% — `meter-low`, до 85% — `meter-mid`, выше — `meter-peak`.
- Значение всегда дублируется текстом `valueText`.
- Движение: деления зажигаются лесенкой при появлении.

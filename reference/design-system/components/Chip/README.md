# Chip

Чипы — аналог Material Chips: капсулы-пилюли трёх видов.

**Потребитель даёт:** `children` (одно-два слова), `kind`: `assist` (действие, `icon` + `onPress`), `filter` (переключатель, `selected` + `onPress`), `input` (введённое значение, `onRemove`). Группу оборачивайте в `ChipGroup` (`label`, `scroll` — в одну прокручиваемую строку).

- Выбранный фильтр заливается акцентом, галочка выпрыгивает с поворотом.
- Нажатие сплющивает чип и отпускает с пружиной, по капсуле проходит глянцевая вспышка.
- Видимая высота 34px, зона касания расширена до 46px.

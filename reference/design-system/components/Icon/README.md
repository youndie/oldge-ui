# Icon

Однотонные глифы 24×24 на `currentColor`.

**Потребитель даёт:** `name`, `size` (16/20/24/28/36), `label` — только если иконка несёт смысл без подписи.

- Цвет задаёт родитель через `color`.
- Полный список имён — `Icon.names`.
- Добавлены для стресс-экранов: `eye`, `eye-off`, `attach`, `send`, `more`, `heart`, `share`, `key`, `mail`.

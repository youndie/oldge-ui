# Panel

Вставная панель на теле экрана: группирует связанный контент.

**Потребитель даёт:** `children`, опционально `title` (маленький, `ink-muted`), `sunken` для вывода только для чтения, `flush` без внутренних отступов (для List внутри).

- Панели не вкладываются друг в друга.
- Для сворачиваемых групп — Accordion.

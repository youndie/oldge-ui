# Tooltip

Подсказка — аналог Material Tooltip: маленькая жёлтая табличка XP над элементом.

**Потребитель даёт:** `label`, дочерний элемент (обычно OrbButton), `placement` (`above` или `below`), `defaultOpen`.

- Показывается при наведении, фокусе и долгом нажатии (450 мс); после касания гаснет через 1,5 с.
- Только для уточнения иконок. Ничего нажимаемого внутри.

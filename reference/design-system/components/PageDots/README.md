# PageDots

Индикатор страниц для каруселей и пейджеров: ЖК-капсулы, текущая растянута и подсвечена.

**Потребитель даёт:** `count`, `index`, `onChange(index)`, `onDark` (поверх фото), `label`.

- Каждая точка — кнопка с зоной касания 44px и подписью «Страница N из M».
- Больше 7 страниц — показывайте счётчик «12 из 148», а не точки.

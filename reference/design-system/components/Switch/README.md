# Switch

Переключатель вкл/выкл: утопленная капсула с хромированным бегунком и лампочкой ON/OFF.

**Потребитель даёт:** `label`, опционально `hint`, `checked`/`defaultChecked`, `onChange(checked)`, `disabled`.

- Включённая капсула заливается акцентом; лампочка дублирует состояние словом.
- Действует сразу; если нужно подтверждение «Сохранить» — используйте Checkbox.
- Внутри ListItem подпись прячьте классом `og-sr`, а заголовок строки остаётся видимым.
- Движение: бегунок растягивается под пальцем и перелетает с отскоком, лампочка мигает при включении.

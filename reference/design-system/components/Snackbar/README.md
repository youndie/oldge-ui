# Snackbar

Снэкбар — аналог Material Snackbar: короткое сообщение в раме скина у нижнего края, с одним действием.

**Потребитель даёт:** `children` (сообщение), `actionLabel` + `onAction` (обычно «Отменить»), `onClose`, `duration` (мс до автоскрытия), `open`; `inline` — без фиксированного положения.

- Выезжает снизу и покачивается, как подвешенная табличка.
- Одно сообщение за раз; для важного, что нельзя пропустить, — Banner или Dialog.

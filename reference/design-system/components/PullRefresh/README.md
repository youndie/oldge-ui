# PullRefresh

Обновление потягиванием: сверху выезжает глянцевый диск, раскручивается вслед за пальцем и крутится, пока идёт обновление.

**Потребитель даёт:** `children` (содержимое прокрутки), `onRefresh`, `refreshing`, `height` (если контейнер не задаёт высоту сам), `label` для скринридера.

- Порог — 64px; когда он пройден, диск подсвечивается акцентом.
- Жест срабатывает только в самом верху прокрутки.
- Дублируйте обновление кнопкой или пунктом меню: жест недоступен с клавиатуры.

# Accordion

Сворачиваемая секция: заголовок-«пилюля» с круглым значком слева и хромированной кнопкой-шевроном справа, под ним — вставная панель.

**Потребитель даёт:** `title`, `icon`, `children`; `defaultOpen` (по умолчанию открыт) или контролируемый `open` + `onToggle`.

- Внутрь обычно кладут `List bare` с `ListItem dense`.
- Секции идут стопкой с зазором `space-3`.
- Заголовок — существительное: «Приложения», «Инструменты».
- Движение: тело разворачивается с пружиной, значок делает оборот, шеврон поворачивается с отскоком.

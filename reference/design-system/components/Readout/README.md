# Readout

Числовое табло на ЖК-стекле со светящимися цифрами и непогашенными «восьмёрками» под ними.

**Потребитель даёт:** `value` (строка с цифрами), `label`, `unit`, `size`.

- Для таймеров, счётчиков, крупных метрик — одно-три табло на экран.
- В каждом скине своё стекло: зелёный неон в Toxic, холодный голубой в Media, серо-зелёный жидкий кристалл без свечения в Crystal.
- Движение: при смене значения цифры мерцают, как у ЖК-табло.

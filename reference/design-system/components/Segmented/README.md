# Segmented

Капсула-переключатель на 2–4 варианта: выбранный сегмент загорается акцентом.

**Потребитель даёт:** `options` `{id, label, icon?}`, `value`, `onChange`, `label` для скринридера.

- Подписи — одно короткое слово.
- Больше четырёх вариантов — Select или RadioGroup.
- Подписи — до 12 символов. Длиннее (немецкий, большой шрифт) — используйте RadioGroup или Select: сегменты переносят текст, но выглядят тесно.

# Fab

Плавающая кнопка действия — аналог Material FAB: скруглённый глянцевый квадрат акцента в хромированной раме.

**Потребитель даёт:** `icon`; `label` — расширенный FAB с подписью; иначе `ariaLabel`; `tone` (`accent` или `chrome`); `expanded` — иконка поворачивается на 135°, и плюс становится крестиком; `docked` — ставит FAB в правый нижний угол над BottomNav.

- Один FAB на экран, только для главного созидательного действия.
- Появляется, вкручиваясь с пружиной; нажатие — сжатие и глянцевая вспышка.
- Если снизу появляется Snackbar, поднимите FAB над ним.

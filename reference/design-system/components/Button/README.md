# Button

Глянцевая кнопка: `primary` — главное действие экрана в цвете акцента скина, `secondary` — серебряный хром, `plain` — текстовая ссылка.

**Потребитель даёт:** `children` (глагол: «Сохранить», «Отправить»), опционально `icon`, `variant`, `size` (`sm` 36px — только в плотных строках; `md` 44px; `lg` 52px — главное действие внизу экрана), `block`.

- Одна `primary` на экран. Рядом — `secondary` для отмены.
- Primary всегда в ободке `accent-rim` (серебро в тёмных скинах, тёмно-зелёный в Crystal): он отделяет салатовую заливку от любого фона. Подпись — тёмная `on-accent`, никогда не белая.
- Только иконка — обязательно `aria-label`; для круглых действий есть OrbButton.
- Нажатие: перевёрнутый градиент, `shadow-sunken`, сдвиг на 1px. Hover не рисуем.
- Движение: при нажатии кнопка сплющивается и отпрыгивает с пружиной, из-под пальца расходится глянцевая вспышка; по primary пробегает блик и гаснет у правого края (при удержании не остаётся на кнопке).

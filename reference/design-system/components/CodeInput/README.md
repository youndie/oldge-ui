# CodeInput

Одноразовый код на ЖК-ячейках: цифры светятся поверх непогашенной «восьмёрки», в активной ячейке мигает курсор.

**Потребитель даёт:** `length` (по умолчанию 6), `value`/`defaultValue`, `onChange(code)`, `onComplete(code)`, `label`, `help`, `error`.

- Под ячейками — одно настоящее поле с `inputmode="numeric"` и `autocomplete="one-time-code"`: вставка, автоподстановка из СМС и скринридер работают как с обычным полем.
- Шесть цифр делятся тире на две тройки — так код легче сверять.
- Ошибка — рамка ячеек, иконка и текст `danger`.

# SearchBar

Строка поиска — аналог Material Search bar: утопленная капсула в хромированном ободке.

**Потребитель даёт:** `placeholder`, `value`/`defaultValue`, `onChange`, `onSubmit`, `trailing` (обычно Avatar), `label`.

- При фокусе лупа покачивается; при вводе появляется круглая кнопка очистки.

# Banner

Баннер — Material Banner в виде информационной полосы XP: жёлтая лента с иконкой, текстом и действиями.

**Потребитель даёт:** `title`, `children`, `icon`, `actions` (Button `sm` `secondary`), `boxed` — отдельной плашкой, а не лентой во всю ширину; `open`.

- Для состояния, которое требует внимания, но не блокирует: мало места, нет сети.
- Выезжает сверху. Кнопки действий — только хромированные: цвета скина на жёлтом не читаются.

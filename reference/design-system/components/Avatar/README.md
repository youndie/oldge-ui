# Avatar

Аватар: круглое лицо в хромированном ободке, с инициалами на раме скина или картинкой, и лампочкой статуса.

**Потребитель даёт:** `name` (из него инициалы и доступное имя), `src` или `icon`, `size` (`sm` 32, `md` 44, `lg` 64), `status` (`online` — пульсирует, `busy`, `away`).

- Статус в доступном имени дублируется словом.

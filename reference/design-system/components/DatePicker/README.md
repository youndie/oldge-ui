# DatePicker

Выбор даты — аналог Material Date picker: календарь месяца на вставной панели с шапкой-пилюлей.

**Потребитель даёт:** `value` (`ГГГГ-ММ-ДД`), `onChange(iso)`, `label`.

- Неделя с понедельника, названия по-русски.
- Сегодня обведено `accent-ink`; выбранный день — глянцевый акцентный шарик, выпрыгивает при выборе.
- Смена месяца сдвигает сетку в сторону перехода.

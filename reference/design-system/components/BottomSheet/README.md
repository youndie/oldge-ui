# BottomSheet

Нижняя шторка — аналог Material Bottom sheet: рама скина с «язычком», заголовком и кнопкой закрытия, внутри тело скина.

**Потребитель даёт:** `title`, `children`, `onClose`, `open`; `inline` — вывести на месте, без затемнения (для документации и встраивания).

- Въезжает снизу с перелётом; тап по затемнению закрывает.
- Внутри — список действий (`List bare`) или короткая форма.

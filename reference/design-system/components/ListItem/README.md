# ListItem

Строка списка: иконка, заголовок, подзаголовок, значение или контрол справа, шеврон.

**Потребитель даёт:** `title`; опционально `subtitle`, `icon`, `value`, `trailing` (Switch, Badge), `chevron`, `selected`, `dense`, `onPress`.

- С `onPress` строка — кнопка целиком, 52px (`dense` — 44px).
- Если справа Switch, не ставьте `onPress`: переключатель сам и есть действие.
- `selected` — сплошной `select`, весь текст — `on-select`.
- Движение: из точки касания по строке расходится глянцевая вспышка, шеврон подталкивается вправо.
- Заголовок переносится на две строки, а не обрезается. В узком списке (меньше 24em — это и 320 dp, и крупный шрифт) значение уходит под заголовок.

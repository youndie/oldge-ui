# CategoryTabs

Ряд крупных глифов-категорий под WindowBar. Подпись показывается только у активной — жирно и подчёркнута «крючком».

**Потребитель даёт:** `items` `{id, icon, label}` (4–8), `value`, `onChange`.

- Неактивные глифы — `ink-muted`, активный — `ink`.
- Ряд прокручивается по горизонтали; под ним зарезервировано место для подписи.
- Подпись — одно-два слова: «Документы», «Фото».
- Это переключение содержимого текущего экрана; для разделов приложения — BottomNav.
- Движение: выбранный глиф подпрыгивает, подпись с «крючком» прорисовывается слева направо.

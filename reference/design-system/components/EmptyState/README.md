# EmptyState

Пустое состояние, ошибка или офлайн: крупный глянцевый шар с иконкой, факт и что делать дальше.

**Потребитель даёт:** `title` (факт: «Всё прочитано»), `children` (одно предложение), `icon`, `tone` (`empty`, `error`, `offline`), `action` (обычно Button).

- Для ошибки действие обязательно — «Повторить» с иконкой `refresh`.
- Шар при появлении подпрыгивает один раз; зацикленной анимации нет.
- Показывайте на месте контента, а не во всплывающем окне.

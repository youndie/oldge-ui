# Select

Выпадающий выбор: хромированная рамка со значением и квадратной акцентной кнопкой-стрелкой справа.

**Потребитель даёт:** `options` `{value, label, icon?}`, `value`, `onChange(value)`, `label`.

- Под рамкой — нативный `select`: на телефоне открывается системный список.
- Для 2–4 вариантов на виду лучше Segmented или RadioGroup.

# BottomNav

Нижний док в безеле скина на 3–5 разделов; иконка активного раздела лежит в хромированной капсуле.

**Потребитель даёт:** `items` `{id, icon, label}`, `value`, `onChange`.

- Нижние углы — `radius-xl`, пара к WindowBar. `square` — без скругления.
- Подписи — одно слово до 9 символов.
- Движение: капсула активной иконки выскакивает, иконка подпрыгивает.

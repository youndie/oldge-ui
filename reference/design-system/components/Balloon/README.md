# Balloon

Жёлтая подсказка из трея XP: неблокирующее уведомление с заголовком, текстом и хвостиком.

**Потребитель даёт:** `title`, текст в `children`, `icon` (`info`, `ok`, `warn`, `error`), `tail` (`bottom`, `top`, `none`), `onClose`.

- Одинакова во всех скинах.
- Заголовок — факт («Копия создана»), текст — что дальше.
- Не для решений: для них Dialog.
- Движение: подсказка надувается от хвостика.

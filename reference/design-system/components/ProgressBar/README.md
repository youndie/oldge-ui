# ProgressBar

Сегментный прогресс-бар XP: акцентные блоки в утопленном колодце.

**Потребитель даёт:** `value` (0..1; без него — бегущие блоки неизвестной длительности), `label`, `detail`, `status` (`done`, `error`).

- `done` и `error` добавляют иконку и слово — статус не передаётся только цветом.
- При `prefers-reduced-motion` бегущие блоки останавливаются.

# Stepper

Шаги мастера — Material Stepper в духе мастеров середины 2000-х: пронумерованные шарики, соединённые жёлобом.

**Потребитель даёт:** `steps` (подписи), `current` (индекс текущего шага), `label`.

- Пройденный шаг — шарик рамы с галочкой; текущий — акцент с пульсирующим кольцом; жёлоб до него заливается.
- От трёх до пяти шагов, подписи — одно слово.

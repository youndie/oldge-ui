# ListSection

Секция списка с заголовком-пилюлей, который прилипает к верху прокрутки.

**Потребитель даёт:** `title`, `meta` (пиксельная метка справа: «3 новых»), `children` (обычно List).

- Прилипание работает внутри прокручиваемого контейнера (`overflow: auto`).
- Заголовки — отрезки времени или группы: «Сегодня», «Вчера», «Ранее».

# Composer

Поле ввода сообщения в раме скина: кнопка вложения, растущее поле, кнопка отправки.

**Потребитель даёт:** `onSend(text)`, `value`/`onChange` (если нужно управлять), `placeholder`, `onAttach` (`false` скрывает скрепку).

- Поле растёт до 120px, дальше прокручивается.
- Enter отправляет, Shift+Enter — перенос строки.
- Кнопка отправки неактивна на пустом поле и выпрыгивает салатовой, когда появился текст.

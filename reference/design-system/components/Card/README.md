# Card

Карточка — аналог Material Card: вставная поверхность с необязательной полосой-заголовком в раме скина, медиа-зоной, текстом и кнопками.

**Потребитель даёт:** `title`, `subtitle`, `children` (текст); `media` (имя иконки или узел) либо `image` + `imageAlt`; `bar` и `barIcon` — полоса-заголовок; `actions` (Button `sm`); `variant` (`raised` или `sunken`); `onPress` — вся карточка становится кнопкой с глянцевой вспышкой.

- Если карточка нажимается целиком, кнопок в `actions` не ставьте: два нажимаемых слоя путают.
- Медиа-зона без картинки — градиент рамы с крупной иконкой; при нажатии иконка подпрыгивает.

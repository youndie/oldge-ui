# TextField

Текстовое поле: подпись сверху, утопленный белый (в тёмных скинах — чёрный) колодец, подсказка или ошибка снизу.

**Потребитель даёт:** `label`, `value`/`defaultValue`, `onChange(value)`, `placeholder`, `help`, `error` (строка), `icon`, любые атрибуты input.

- Ошибка: рамка и текст `danger` плюс иконка — не только цвет.
- Плейсхолдер — пример, не подпись.
- `reveal` — поле пароля с круглой кнопкой «показать/скрыть» внутри; `multiline` (+ `rows`) — многострочное поле.
- Высота поля растёт вместе с текстом: при крупном системном шрифте ничего не обрезается.

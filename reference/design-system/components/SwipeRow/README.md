# SwipeRow

Строка, у которой смахиванием влево открываются действия.

**Потребитель даёт:** `children` (обычно ListItem), `actions` `{icon, label, tone, onPress}` (1–3; `tone`: `chrome`, `accent`, `danger`), `defaultOpen`.

- Строка едет за пальцем, за краем сопротивляется, отпущенная — докатывается с пружиной.
- Жест начинается только при горизонтальном движении, вертикальная прокрутка не ломается.
- Действия остаются в порядке табуляции: фокус на действии сам открывает строку. Для скринридера их нужно дублировать в меню строки.
- Удаление — `danger` последним, справа.

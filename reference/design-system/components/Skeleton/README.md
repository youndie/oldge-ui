# Skeleton

Заглушка загрузки: пустые утопленные «слоты» со строчной развёрткой, по которым ходит сканер — комета из салатовых XP-сегментов, качающаяся туда-обратно. Строки идут не в фазе, поэтому блок читается как бегущая волна. Круг — сегментный циферблат, по которому шагает подсвеченная дуга.

**Потребитель даёт:** `variant` — `text` (+ `lines`), `circle`, `rect` (+ `height`, `icon` — призрачный глиф в центре), `row` (аватар и две строки), `card` (медиа, аватар и строки); `width`, `index` — сдвиг фазы, если несколько скелетов стоят подряд. Контейнеру поставьте `aria-busy="true"`.

- Повторяйте форму будущего контента: `row` под строку списка, `card` под Card.
- Ширины строк заданы «рваной» лесенкой, последняя строка короче — чтобы блок выглядел как текст, а не как таблица.
- Показывайте не дольше пары секунд; дальше — Spinner с подписью.
- При `prefers-reduced-motion` сканер и дуга стоят.

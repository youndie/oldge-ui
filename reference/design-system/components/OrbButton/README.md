# OrbButton

Круглая глянцевая кнопка в хромированном ободке — как кнопки окна и круглые кнопки действий в углу пусковых оболочек.

**Потребитель даёт:** `icon`, `label` (обязательно — это доступное имя), `size`, `tone`.

- `sm` (30px в зоне 44px) — кнопки в WindowBar и Dialog: справка, свернуть, закрыть.
- `md` (48px) — вторичные круглые действия; `lg` (60px) — одно плавающее главное действие.
- `tone`: `bezel` — цвет скина (по умолчанию), `accent` — главное действие, `chrome` — нейтральное.
- Не больше трёх орбов в ряд.
- Движение: ободок сжимается при нажатии, в ядре расходится глянцевая вспышка.

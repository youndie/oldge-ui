# ActionTile

Действие в стиле пусковой оболочки: крупный круглый глянцевый значок и жирная подпись, без карточки.

**Потребитель даёт:** `title` (глагол: «Загрузить файлы»), `description` (одна строка), `icon`, `tone`, `layout` (`row` или `stack` для сетки), `onPress`.

- Раскладка — сетка в две колонки или стопка.
- `tone`: `chrome` — по умолчанию, `accent` — одно главное действие сетки, `bezel` — второстепенное в цвете скина.
- В сетке из двух колонок подпись — одно-два коротких слова (до 12 символов в строке), иначе нужна раскладка `row` в одну колонку.
- При нажатии под плиткой проступает утопленная панель.
- Движение: глянцевая вспышка, значок сжимается и поворачивается при нажатии.

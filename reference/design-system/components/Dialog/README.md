# Dialog

Диалог-окно: рамка безеля, заголовок с кнопкой-орбом «закрыть», тело на фоне скина, кнопки справа внизу.

**Потребитель даёт:** `title` (вопрос или факт), `children` (одно-два предложения), `actions` (Button: сначала отмена, потом primary), `icon`, `onClose`, `modal` (затемнение и `role="dialog"`), `open`.

- Деструктивное действие — primary с иконкой `trash` и глаголом «Удалить», не «OK».
- Управление фокусом при открытии остаётся за приложением.
- Движение: окно раскрывается с пружиной из-под центра.

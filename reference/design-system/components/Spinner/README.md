# Spinner

Индикатор загрузки — аналог Material Circular progress: вращающийся глянцевый диск с отверстием, цвета скина переливаются по кругу.

**Потребитель даёт:** `size` (`sm` 24px, `md` 48px, `lg` 72px), `label` — подпись под диском и имя для скринридера.

- Для неизвестной длительности. Если прогресс известен — ProgressBar.
- При `prefers-reduced-motion` диск стоит, подпись остаётся.

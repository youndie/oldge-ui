# WindowBar

Верх экрана: безель скина с заголовком, как заголовок окна. Справа — маленькие OrbButton.

**Потребитель даёт:** `title`; `icon` на корневом экране или `onBack` на вложенном; `subtitle`; `center` (бейдж или компактный переключатель); до трёх `actions` `{icon, label, onPress, tone}`.

- Верхние углы — `radius-xl`: экран читается как окно. `square` убирает скругление, если бар стоит впритык к системному статус-бару.
- Заголовок — стиль `title`, с тенью текста.
- Не кладите поиск и табы внутрь бара: для разделов есть CategoryTabs.
- `lead` — узел перед заголовком вместо иконки, например Avatar в чате.
- `overlay` — прозрачный бар с тёмной вуалью для экранов с медиа на весь экран; рамы нет, текст белый с тенью.

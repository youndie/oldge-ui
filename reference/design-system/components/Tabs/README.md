# Tabs

Вкладки — аналог Material Tabs в стиле листа свойств XP: выбранная вкладка приподнята и сливается с панелью, сверху — полоска акцента.

**Потребитель даёт:** `items` `{id, label, icon?, badge?}`, `value`, `onChange`, `label`; `children` — содержимое активной вкладки (рисуется в панели под ними).

- Полоска акцента выстреливает из центра с отскоком, панель проявляется.
- От двух до пяти коротких вкладок; больше — CategoryTabs.

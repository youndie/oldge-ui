# ChatBubble

Пузырь сообщения. Свои — глянцевая пилюля цвета скина справа, чужие — вставная панель слева с аватаром.

**Потребитель даёт:** `from` (`me` или `them`), `children` (текст), `time`, `status` (`sent`, `read`), `avatar`, `author` (для групповых чатов), `tail` (`false` у не последних сообщений группы).

- Подряд идущие сообщения одного автора группируются: время, статус, аватар и хвостик — только у последнего.
- Длинные слова и ссылки переносятся, пузырь не шире 86% ленты.
- Появляется, надуваясь от угла с хвостиком.

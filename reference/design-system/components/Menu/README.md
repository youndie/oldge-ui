# Menu

Выпадающее меню — аналог Material Menu в стиле меню XP: цветная полоса слева под иконками, синее выделение пункта.

**Потребитель даёт:** `trigger` (любая кнопка, ей добавляются `onClick` и `aria-expanded`), `items` `{id, label, icon?, hint?, danger?}` и `{divider: true}`, `onSelect(id)`, `align` (`start` или `end`), `label`.

- Раскрывается из угла с пружиной, пункты проявляются лесенкой.
- Закрывается выбором, тапом снаружи или Escape.
- Разрушительный пункт — последним, после разделителя, с `danger`.
